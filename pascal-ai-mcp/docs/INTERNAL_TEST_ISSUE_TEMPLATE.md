## 无法获取 ID 时

三层服务未启动、代理在请求到达 AI 前失败、页面无法加载或 readiness 配置错误时可能没有 requestId。此时至少提供 commit、时间、访问地址、HTTP 状态、复现步骤和脱敏截图。维护者先按时间与服务层定位，不能因为缺少 requestId 就判定无法复现。

## 截图与录屏

- 保留必要的 sceneId/requestId 与问题区域；
- 遮盖用户名、项目名、地址、密钥和无关场景内容；
- 不拍摄 `.env`、数据库浏览器或完整网络请求 header；
- 视觉问题尽量同时提供全景与局部；
- 动态问题从问题发生前一步开始录制，并注明时间。
